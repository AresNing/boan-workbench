# Changelog

## 0.8.0 — Initial public MVP — 2026-09-08

- Task-first macOS workbench with independent project execution, dependencies, bounded auxiliary work, verification and explicit acceptance.
- Project navigation, grouped activity, result previews, attachments and per-task model parameters.
- Chinese and English UI, system-language option, native menu localization, persisted app preferences and preserved user text.
- ChatGPT/Codex sign-in, Claude sign-in and API model services with local credential storage.
- MIT-licensed source, bilingual documentation, public npm lockfile and macOS CI.

Earlier local development versions were not public releases. Binary installers are not included in this source MVP.
